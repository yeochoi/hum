# Button

One job per style.

- Primary. `primary` fill, white `title`, 54 tall, `radius-pill`. The one main action, like Save, Done, Import songs.
- Soft. `soft` fill with `blue-text`. Secondary actions like New playlist and Add songs.
- Hero pair. Play and Shuffle on the hero, 48 tall. Play is `primary`, Shuffle is white at 10 percent.
- Remove. Plain `coral-text`, centered, always last.
