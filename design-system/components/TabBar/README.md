# TabBar

Songs and Playlists, with the add button beside them.

- A floating glass pill, bottom left, 14 above the safe area. White at 72 percent, blur 20, saturate 1.6, `shadow-float`.
- Line icons at 25 with `small` labels. The current tab gets a `soft` pill that slides between tabs, `blue-text` label and a `primary` icon.
- The add button is 62 round in `primary` and always means Import songs.
